# 🏠 House Price Prediction Dataset – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the Ames Housing Dataset from Kaggle.

The main objective is to understand the factors that influence house sale prices through data analysis, statistical methods, and visualizations.

This project focuses on data exploration and does not include machine learning model development.

## 🎯 Objectives

- Understand the structure and characteristics of the dataset.
- Analyze numerical and categorical variables.
- Study the distribution of house sale prices.
- Identify relationships between house features and sale prices.
- Detect potential outliers using IQR and Z-score.
- Analyze missing values and data quality.
- Create meaningful visualizations and an EDA dashboard.

## 📂 Dataset Information

- **Dataset:** House Prices – Advanced Regression Techniques
- **Source:** Kaggle
- **Rows:** 1,460
- **Original Columns:** 81
- **Target Variable:** SalePrice

Dataset link: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

Two additional columns, `LogSalePrice` and `Outlier`, were created during analysis.
