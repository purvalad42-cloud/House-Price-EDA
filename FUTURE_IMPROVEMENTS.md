
# Limitations and Future Improvements

## Current Project Scope
- Focuses on Exploratory Data Analysis (EDA).
- Uses Python libraries for data analysis and visualization.
- Studies the relationships between housing features and SalePrice.
- Does not include machine learning or house price prediction.

## Current Limitations
- Analysis is based on one housing dataset.
- Some columns contain missing values.
- Correlation does not prove causation.
- Outliers are identified but not automatically removed.

## Future Improvements
- Apply machine learning models to predict house prices.
- Compare Linear Regression, Decision Trees, and Random Forest.
- Perform feature engineering.
- Improve missing-value handling.
- Build an interactive dashboard using Streamlit.
- Deploy the project as a web application.

## Conclusion
This project provides a foundation for understanding housing data. Future improvements can extend it into a complete house price prediction application.
