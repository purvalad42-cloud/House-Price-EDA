
# EDA Methodology

This document describes the steps followed during Exploratory Data Analysis of the Ames Housing Dataset.

## 1. Data Loading and Inspection
- Imported the dataset using Pandas.
- Checked the number of rows and columns.
- Examined the first few records.
- Checked data types and missing values.

## 2. Variable Classification
- Identified numerical variables.
- Identified categorical variables.
- Classified important ordinal variables.

## 3. Descriptive Statistics
- Calculated mean, median and mode.
- Examined standard deviation and variance.
- Calculated minimum, maximum and interquartile range.

## 4. Univariate Analysis
- Created histograms and boxplots.
- Analyzed SalePrice distribution.
- Compared house prices across neighborhoods.

## 5. Correlation Analysis
- Calculated Pearson correlation.
- Examined covariance.
- Identified features strongly associated with SalePrice.

## 6. Data Visualization
- Created scatter plots.
- Created pair plots.
- Generated a correlation heatmap.

## 7. Outlier Detection
- Applied the IQR method.
- Applied the Z-score method.
- Compared the detected outliers.

## 8. Data Quality Checks
- Checked duplicate records.
- Examined missing values.
- Inspected data types and unusual values.

## 9. Final Dashboard
- Combined four important visualizations.
- Summarized the major findings.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy and Google Colab.
