
# Dataset Information

## Dataset Name
House Prices - Advanced Regression Techniques

## Source
Kaggle

Dataset Link:
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

## Dataset Details

- Number of Rows: 1,460
- Original Number of Columns: 81
- Main File: train.csv
- Target Variable: SalePrice

## Important Features

| Feature | Description |
|---|---|
| SalePrice | Final sale price of the house |
| OverallQual | Overall material and finish quality |
| GrLivArea | Above-ground living area |
| TotalBsmtSF | Total basement area |
| GarageArea | Garage area |
| YearBuilt | Original construction year |
| Neighborhood | Physical location within Ames |

## Note

During EDA, two additional columns were created:
- LogSalePrice
- Outlier

These columns were added for analysis purposes.

The original dataset was downloaded from Kaggle and analyzed using Google Colab.
